Discrete uniform
Every value in a list is equally likely (a fair die).
Bernoulli
One trial with two outcomes: success or failure.
Binomial
Number of successes in n independent trials.
Geometric
Number of trials needed to get the first success.
Hypergeometric
Number of successes when sampling without replacement.
Poisson

1 · What is a random variable?

A random experiment is a process whose result is uncertain, such as tossing a coin or counting the students absent today. A random variable turns each outcome into a number.

Notation: a capital letter (X) names the random variable. A lowercase letter (x) is one particular value it can take. P(X = x) means “the probability that X equals x”.

🪙 Example

Toss a fair coin 3 times. Let X = the number of heads. The outcomes HHH, HHT, HTH, … are turned into the numbers x = 0, 1, 2 or 3. Nothing else is possible, so X has only four values.

Discrete or continuous?

A random variable is discrete if its possible values can be counted: a finite list, or an unending list such as 0, 1, 2, 3, … It is continuous if it is measured and can take any value in an interval, including decimals.

2 · Describing a discrete random variable

A discrete random variable X takes countable values x₁, x₂, x₃, … Its probability distribution function (PDF) lists every value with its probability, P(x) = P(X = x). You can show it as a table, a formula, or a graph.

📝 Terminology: Many textbooks call this the “probability distribution function (PDF)” for a discrete variable. Strictly, it is the probability mass function (pmf), and “PDF” is normally kept for continuous variables. You may see either name, so know both.
⚖️ Two rules every PDF must satisfy
1)  0 ≤ P(x) ≤ 1 for every x     2)  Σ P(x) = 1 (all probabilities add to 1)

Centre and spread

Mean (expected value):  μ = E(X) = Σ x · P(x)
Variance:  σ² = Σ (x − μ)² · P(x) = E(X²) − μ²
Standard deviation:  σ = √σ²

The mean is the long-run average over many repetitions. It does not have to be a possible value of X. The standard deviation measures how far values typically fall from the mean.

4 · Which distribution fits?

Before calculating, ask these questions in order:

  1. Is there only one trial? → Bernoulli
  2. Are all values in a list equally likely? → Discrete uniform
  3. Are we counting successes in a fixed number of trials?
    • Independent trials (or sampling with replacement) → Binomial
    • Sampling without replacement from a small population → Hypergeometric
  4. Are we counting trials until the first success? → Geometric
  5. Are we counting events in an interval of time or space, with a known average rate? → Poisson

🔬 What-if: quality control sampling

A packing line produces items with a defect rate p. You inspect a sample of n items and reject the batch if you find at least one defective. How likely is a rejection?

Rule used: P(at least one) = 1 − P(X = 0) = 1 − (1 − p)n. Notice how a larger sample catches problems much more reliably.
